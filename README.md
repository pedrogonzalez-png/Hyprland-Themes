# end4-pC Character Themes

Temas personalizados para end4-pC e Fastfetch no Arch Linux.

## Temas disponíveis
- Changli — Wuthering Waves
- Hiyuki — Wuthering Waves
- Emilia — Re:Zero
- Furina — Genshin Impact
- Hotline Miami

## Estrutura
- end4-pC/: paletas JSON para o end4-pC
- fastfetch/: configurações JSON para o Fastfetch

## Instalação
Copie o JSON desejado da pasta end4-pC para ~/.config/illogical-impulse/schemes/ e selecione o tema no end4-pC.

Para o Fastfetch, utilize a configuração correspondente ao personagem escolhido.

## Observações
Não inclui wallpapers, arquivos pessoais ou configurações do sistema.
